# AI Code Generator System (LLM-based Assistant) 🚀

## 📌 Overview
CodePilotAI is a multi-agent AI system that converts natural language requirements into interactive web UI applications using LangChain and Groq LLMs. It automates frontend code generation by breaking down user prompts into structured UI components.

---

## ⚙️ Features
- 🧠 Multi-agent architecture (Planner, Frontend Agent, Integration Agent)
- 💬 Natural language to UI code generation
- 🎨 Automatic HTML, CSS, and JavaScript generation
- 🔄 Iterative task decomposition using LLM orchestration
- ⚡ Fast code synthesis using Groq LLMs

---

## 🏗️ Architecture
The system uses an agent-based workflow:

1. **Planner Agent**
   - Breaks user prompt into structured tasks

2. **Frontend Agent**
   - Generates HTML, CSS, JS code

3. **Integration Agent**
   - Combines and finalizes UI components

---

## 🛠️ Tech Stack
- Python 🐍
- LangChain 🧠
- Groq LLM API ⚡
- LangGraph 🔗
- HTML / CSS / JavaScript (generated output)

---

## 📂 Example Outputs
- Photo Gallery UI (upload & display interface)
- Calculator App UI
- Basic interactive web components

---

## 🚀 How it works
User Prompt ➝ Planner Agent ➝ Task Breakdown ➝ Frontend Agent ➝ Code Generation ➝ Final UI Output

---

## 📌 Project Goal
To automate frontend development using multi-agent LLM orchestration and reduce manual UI coding effort.
