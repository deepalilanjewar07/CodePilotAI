# AI Multi-Agent Code Generation System 🤖 (Work in Progress)

## 📌 Overview
This project is an AI-powered multi-agent system that generates web applications from natural language prompts using LLMs. It uses LangChain and Groq models to automatically generate frontend (HTML, CSS, JavaScript), backend APIs, and database structure.

⚠️ This project is currently under development and is not production-ready.

---

## ⚙️ Features
- Multi-agent architecture (Planner, Frontend, Backend, Database agents)
- Converts natural language into structured application code
- Generates frontend UI (HTML, CSS, JavaScript)
- Generates backend API structure (FastAPI)
- Generates database layer including:
  - DB connection setup (`db.py`)
  - Schema/models definition (`models.py`)
- LLM-driven orchestration using LangChain + Groq

---

## 🧠 Tech Stack
- Python  
- LangChain  
- Groq LLM  
- FastAPI   
- HTML, CSS, JavaScript  

---

## 🚀 Workflow
User Prompt → Planner Agent → Code Generation Agents → Frontend + Backend + Database Output
